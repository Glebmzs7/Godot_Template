# Class_Json

## Назначение
Чтение и запись JSON-файлов, в которых лежит словарь (`Dictionary`). Через него работают настройки, список аккаунтов, файлы логов и реестр потоков, manifest файлов и база пользователей сервера.

## Как подключать
`var Class_Json = load("res://Godot_Template/Class_Json.gd").new()` — у каждого использующего свой экземпляр. Наследует `Object`, а не `RefCounted`, поэтому память сама не освобождается. Экземпляры живут всю программу, так что на практике это не мешает.

## Переменные
| Имя | Что хранит |
|---|---|
| `vGS_LastPath` | Путь последнего успешно загруженного/сохранённого файла |
| `vGD_LastJson` | Последний успешно загруженный/сохранённый словарь |

## Функции

### fxG_LoadJson_Cr(vGS_Path) -> Dictionary
Открывает файл, парсит JSON. Возвращает словарь или `{}`, если файл не открылся или в нём не словарь (ошибка — `push_error`). При успехе обновляет `vGS_LastPath`/`vGD_LastJson`.

### fxG_SaveJson_Ch(vGS_Path, vGD_Data)
Сохраняет словарь в файл (JSON с табуляцией). **Папки не создаёт** — это сделано намеренно, папки создаются руками. Если папки назначения нет, пишет понятную ошибку с именем отсутствующей папки и ничего не сохраняет.

### fxG_OverwriteLastJson_Ch(vGD_NewData)
Перезаписывает последний использованный файл (`vGS_LastPath`) новым словарём. Если файла ещё не было — ошибка.

### fxG_MergeJsonFiles_Tr(vGS_Source, vGS_Target, vBv_Overwrite = true) -> Dictionary
Копирует ключи верхнего уровня из одного JSON-файла в другой и сохраняет результат в целевой файл. При `vBv_Overwrite = false` существующие ключи не трогает. Слияние неглубокое: вложенные словари заменяются целиком.

## Известные проблемы
- Имена функций в старом стиле (`_Cr`/`_Ch`/`_Tr`), не по [[README]].
- Ошибки уходят только в `push_error` — вызывающий код узнаёт о них лишь по пустому `{}`.

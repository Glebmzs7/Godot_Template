# Class_FileIntegrity

## Назначение
Отпечатки файлов для проверки `"ThirdPartyFiles"` (целостность файлов программы). Одни и те же функции используют:
- клиент — что отправить на проверку;
- сервер — что хранить в manifest и чем проверять присланное.

## Как подключать
Все функции `static` — экземпляр не нужен: `Class_FileIntegrity.fC_BuildFingerprint_Cr(path)`.

## Что проверяется
Все файлы под `res://`, кроме индивидуальных для конкретной установки и служебных:
`EXCLUDED_PREFIXES_A = ["res://Save/", "res://.godot/", "res://.import/", "res://.git/"]`.

## Форматы
- **Отпечаток (клиент → сервер):** `{"Path", "Size", "FirstByte", "LastByte", "RandomIndex", "RandomByte"}`. Случайный байт выбирается заново при каждом вызове.
- **Запись manifest (сервер):** `{"Size", "FirstByte", "LastByte"}` — без случайного байта. Его сервер читает «живьём» из своей копии файла.
- **Пустой (0 байт), но существующий файл** даёт честную запись: `Size = 0`, байтовые поля `-1`. `{}` возвращается **только** если файла нет. Так опустошённый файл ловится как несовпадение, а не выпадает из проверки.

## Функции
- **`fC_ListCheckableFiles_Cr(vGS_Root_S = "res://") -> Array`** — рекурсивно собрать пути всех проверяемых файлов. Внутри — `_fL_WalkDirectory_Ch`, `_fL_IsExcluded_Bv`.
- **`fC_BuildFingerprint_Cr(vGS_Path_S) -> Dictionary`** — отпечаток файла для отправки.
- **`fC_BuildManifestEntry_Cr(vGS_Path_S) -> Dictionary`** — запись manifest.
- **`fC_ReadByteAt_I(vGS_Path_S, vGI_Index_I) -> int`** — байт по индексу из реального файла (сервер проверяет случайный байт клиента). `-1`, если индекс вне файла или файл не прочитан: это значение никогда не совпадёт с настоящим байтом.

## Известные проблемы / открытые вопросы
- **Охват слишком широкий при запуске из редактора.** Под `res://` видны файлы, которых не будет в экспорте (`.gd.uid` и т.п.). Пока manifest пересобирается на той же машине перед проверкой, это не мешает. Перед релизом список исключений нужно пересмотреть.
- **Планировалось сузить проверку до «файлов, заранее известных серверу»** — сейчас проверяется всё неисключённое, а посторонние файлы ловятся как `Unexpected`.
- **Нет переключателя «выключить проверку совсем»** для релизной сборки — см. [[Сцена StartServer]] (`REGENERATE_MANIFEST_ON_START_Bv`).
- Файл читается целиком, чтобы взять 3 байта: для больших файлов это медленно.
- Имена функций в старом стиле, не по [[README]].

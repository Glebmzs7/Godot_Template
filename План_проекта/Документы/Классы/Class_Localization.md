# Class_Localization

## Назначение
Обёртка над встроенной локализацией Godot (`TranslationServer`/`Translation`). Переводы читаются из CSV прямо кодом, без импорта через редактор: проект собирается кодом, и редакторский импорт сюда не вписывается. Используется экраном настроек в [[Сцена Start_Program]].

## Как это работает
- Источник переводов — `res://Localization/Localization.csv`. Первая строка — заголовок `keys,ru,en,de,fr,es`, дальше строка на ключ (сейчас 66 ключей). Значения — настоящие переводы.
- На каждую локаль создаётся `Translation`, наполняется ключами и регистрируется через `TranslationServer.add_translation()`.
- **В конфиге ноды вместо текста пишется сам ключ** (например `"SETTINGS_TITLE"` в `Button.text`). Godot переводит его при отрисовке сам (`auto_translate_mode` включён по умолчанию) и сам обновляет надписи при смене языка. Вручную вызывать `tr()` или перестраивать ноды не нужно.
- Парсер простой: **запятые внутри значений не поддерживаются** (экранирования нет).

## Переменные
| Имя | Значение | Смысл |
|---|---|---|
| `FileLocalization` | `res://Localization/Localization.csv` | Файл переводов |
| `SupportedLocales_A` | `["ru", "en", "de", "fr", "es"]` | Список языков для настроек; дублирует заголовок CSV, порядок тот же |
| `_vGB_Loaded_Bv` | `false` | Загружены ли переводы (повторная загрузка не нужна) |

## Функции
- **`fxG_LoadLocalization_Ch() -> String`** — загрузить CSV и зарегистрировать переводы. Возвращает `""` при успехе или понятное описание проблемы (нет файла, пустой, битый). Сам **не** делает `push_error`: решение, как показать ошибку, остаётся за вызывающим кодом. Start_Program пишет её в лог и в окно информации, программа продолжает работать (без переводов видны сырые ключи).
- **`fC_DetectSystemLocale_S() -> String`** — язык системы (`OS.get_locale()`, первые 2 буквы) среди поддерживаемых, иначе `"en"`. Используется, пока язык в настройках не выбран явно.
- **`fC_SetLocale_Ch(vLS_LocaleCode)`** — переключить язык движка. Все переводимые надписи обновятся сами.
- **`fC_FilterLocalesByInputScript_A(vLS_Query_S) -> Array`** — фильтр списка языков по поисковому запросу. Определяет алфавит введённых символов (кириллица / хирагана-катакана / иероглифы / латиница) и возвращает языки с этим «родным» алфавитом. Пустой запрос — весь список. Сейчас при вводе латиницы предлагаются сразу en, de, fr, es.

## Известные проблемы
- Нет поддержки запятых и кавычек в значениях CSV.
- Список `SupportedLocales_A` дублирует заголовок CSV — при добавлении языка нужно править оба места.
- Имена функций в старом стиле, не по [[README]].

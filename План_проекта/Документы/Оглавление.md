# Оглавление документации Godot_Template

Документация разделена на две части:
- **Документы** (эта папка) — как всё работает СЕЙЧАС. Описывает текущее состояние кода, без истории правок.
- **Журнал** (`План_проекта/Журнал`) — что, когда и почему меняли. История, обсуждения, прежние версии описаний.

Правило: когда меняется код — обновляется соответствующий документ (текущее состояние) и дописывается запись в журнал (что изменилось). Поле `checked` в свойствах документа — дата последней сверки документа с кодом.

Стандарт оформления кода — [[README]] (`Сам проект/README.md`). Заготовки конфигов нод для [[Class_UI]] — [[ShablonUI]] (`Сам проект/ShablonUI.md`). Политика веток — [[BRANCHES]], обновление шаблона в проектах-потребителях — [[UPDATING]].

## Все документы (автоматически, Dataview)

```dataview
TABLE type AS "Тип", status AS "Статус", path AS "Путь в проекте", checked AS "Сверено с кодом"

WHERE type AND type != "оглавление"
SORT type ASC, file.name ASC
```

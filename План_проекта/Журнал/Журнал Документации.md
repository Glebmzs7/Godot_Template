# Журнал Документации

История самой документации: структура, правила, крупные переработки. Новые записи — сверху.

## Записи

### 2026-09-26 — решение: имена функций приводятся к README постепенно
Массового переименования не делаем. При любой правке файла кода функции, которые в ней затронуты, переименовываются по стандарту [[README]] (окончание `_X1X2X3X4`); в журнале этого файла делается запись о переименовании.

### 2026-09-26 — заголовок README
`Сам проект/README.md`: заголовок `# Power_struggle` заменён на `# Godot_Template`. Остальной текст README не менялся.

### 2026-09-26 — разделение на Документы и Журнал, полная сверка с кодом
**Решение пользователя:** документация делится на две части.
- `План_проекта/Документы/` — **описание работы**: только текущее состояние, без истории. Подпапки `Классы/`, `Сцены/`, `Планы/`, плюс [[Обзор проекта]] и [[Оглавление]].
- `План_проекта/Журнал/` — **что и как меняли**: по одному файлу `Журнал <имя>.md` на каждый документ + этот общий журнал.

**Что сделано:**
- Все документы переписаны заново по коду на 26.09. Прежние заметки отставали: пути `res://Class/` вместо `res://Godot_Template/`; сетевые классы помечены «код не написан»; [[Class_UI]] описан по старым именам функций и старому формату конфига; в [[Обзор проекта]] автозагрузка `Analytics` вместо `Logger`.
- Новые документы: [[Class_Localization]], [[Сцена StartServer]], [[Сцена TestInterface]], [[Сцена TestLogger]], [[Оглавление]].
- У каждого документа — свойства (properties): `type`, `status`, `path`, `extends`, `depends`, `checked` (дата сверки с кодом), `journal`. Ключи латиницей, значения по-русски. [[Оглавление]] строит по ним таблицу через Dataview.
- Прежний текст каждой заметки перенесён без изменений в её журнал (раздел «Прежний текст документа»). Туда же добавлен краткий список датированных записей changelog из комментариев в коде.
- Прежние 13 файлов в корне `План_проекта/` удалены (их содержимое целиком в журналах).

**Найдено при сверке** (записано в документы как «Известные проблемы», код не менялся):
- Имена функций в коде в основном не по стандарту [[README]] (окончание `_XXXX` есть только у 9 функций из ~200).
- [[Class_ArrayAndOrDictionary]] передаёт в логирование класс `Class_Logger` вместо экземпляра `Logger`.
- [[Сцена TestInterface]] проверяет исправление, которого в [[Class_UI]] нет, и, скорее всего, проходит ложно.
- Изменения кода 11–12.09 не записаны в changelog-комментариях.
- В `Localization.csv` нет ключа `ACCOUNT_PICKER_TITLE`.
- [[ShablonUI]] использует названия свойств Godot 3.

**Правило на будущее:** изменил код → обнови документ (текущее состояние, поле `checked`) → добавь запись сверху в журнал этого документа.

## Class_Help

Путь: `res://Class/Class_Help.gd`
Наследует: `Node`
Класс: `Class_Help`

### Для чего нужен
Общая «коробка с инструментами» для работы с данными любого типа: словарь понятных названий типов Godot, списки «с чем можно перебирать» (итерируемые и массивоподобные типы) и универсальный механизм вызова функции по описанию. Сам по себе отдельную задачу не решает — на него опираются [[Class_ArrayAndOrDictionary]] и [[Class_Logger]] (оба создают у себя `Class_Help = load(...).new()`).

### Переменные

#### TYPE_NAMES
Словарь: числовой код типа Godot (`TYPE_INT`, `TYPE_STRING` и т.д.) → человекочитаемое имя ("Int", "String"...). Нужен, чтобы в отладочных сообщениях выводить не число, а понятное имя типа.

#### ITERABLE_TYPES
Словарь-множество: какие типы можно перебирать в цикле (`Array`, `Dictionary` и все `Packed*Array`). Используется, чтобы решить, «нырять» ли внутрь значения при обходе структуры.

#### ARRAY_TYPES
Словарь-множество: какие типы ведут себя как массив (`Array` и все `Packed*Array`, без `Dictionary`). Используется, когда нужно отличить «это массив» от «это словарь».

> ⚠️ Несостыковка: в [[Class_ArrayAndOrDictionary]] и [[Class_UI]] встречаются обращения к `Class_Help.ITERABLE_TYPES_MAP` и `Class_Help.ARRAY_TYPES_MAP` — переменных с суффиксом `_MAP` в файле нет, есть только `ITERABLE_TYPES` и `ARRAY_TYPES`.

### Функции

#### get_iter_keys(container)
- Назначение: получить список «ключей», по которым можно перебрать любую структуру данных.
- Как пользоваться: передать `Dictionary` или массивовидный контейнер — получить `keys()` для словаря или `range(size())` для массива; для всего остального — `null`.
- Входные данные: `container` — любое значение.
- Выходные данные: `Array` ключей/индексов либо `null`, если контейнер не перебираемый.
- Принцип работы: определяет тип через `typeof()`, для словаря отдаёт `.keys()`, для массивовидных типов — `range(container.size())`.
- Используется в: [[Class_ArrayAndOrDictionary#UniversalBypass]].

#### FunctionCall(FuncParametrs, EmbeddedParameters = null)
- Назначение: единая точка вызова «функции по описанию» — вместо прямого вызова `func.call(...)` передаётся словарь с самой функцией и её параметрами, что позволяет обходам структур одинаково дёргать разные callback-и.
- Как пользоваться: передать `{"func": <Callable>, "Parametrs": [...]}`; при необходимости вторым аргументом добавить ещё параметры (`EmbeddedParameters`), которые объединятся с уже заданными (словари — через `merge`, массивы — через `+`).
- Входные данные: `FuncParametrs: Dictionary` — обязательно ключ `"func"` (Callable), опционально `"Parametrs"` (Array/Dictionary); `EmbeddedParameters` — дополнительные параметры того же типа.
- Выходные данные: то, что вернула вызванная функция (`Variant`), либо ничего при ошибке (с сообщением через `push_error`).
- Принцип работы: проверяет, что `"func"` задан и это `Callable`; собирает итоговый список параметров (объединяя `Parametrs` и `EmbeddedParameters`, если типы совпадают); вызывает `FuncParametrs["func"].call(Parametrs)`.
- Используется в: [[Class_ArrayAndOrDictionary#fC_OvergrowthIf_Tr]], [[Class_Logger#fC_OvergrowthIf_Tr]] — это тот самый механизм, через который эти функции вызывают переданный им callback на каждом шаге обхода словаря.

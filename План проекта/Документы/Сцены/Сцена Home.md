# Сцена Home

## Назначение
Главный экран приложения, на который [[Сцена Start_Program]] переключается кнопкой «Войти» (`Class_UI.fxC_SwitchingScene_0000("res://Scenes/UIScenes/Home/Home.tscn")`).

**По задумке:**
- нижняя панель с разделами «Чек-листы», «Дела», «Состояние / Здоровье», «Финансы»;
- верхняя панель со счётчиком прожитого времени и кнопкой настроек.

## Текущее состояние
**Пустая заготовка.** Корень — `Control` на весь экран, скрипт `home.gd` содержит только пустой `_ready()`. Прежнее нерабочее содержимое убрано 24.08. Его полный текст сохранён в журнале — [[Журнал Сцена Home]].

## Что нужно для реализации
- Собирать экран так же, как [[Сцена Start_Program]]: конфиг → [[Class_UI]] (`add_child(Class_UI)` обязателен).
- Логировать в свой поток [[Class_Logger]]. Логгер уже запущен в Start_Program, повторно `fxG_StartingLogger_CrTr` не вызывать.

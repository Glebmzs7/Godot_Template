# Ветки GIT_automation

Та же модель, что и в остальных проектах (Godot_Template, Life_Operator, Power_struggle):

- **Stable** — ветка по умолчанию на GitHub. Финальный, проверенный код. Отсюда самообновляется
  "рабочая" копия AutoSync (та, что реально следит за проектами каждый день).
- **Beta** — промежуточный этап проверки перед Stable (пока не используется активно — заведена
  по аналогии с остальными проектами, на будущее).
- **alpha/Mzs7** — рабочая ветка разработчика. Здесь пишется и тестируется новый код, отсюда
  самообновляется "копия для разработки" AutoSync.

## Как код доходит от alpha до Stable

Пока — вручную (см. "Планы_Будущего" в проекте IT в claude.ai): разработчик сам решает, когда
alpha/Mzs7 достаточно проверена, и делает merge в Stable на GitHub.

## Самообновление

См. `Сам проект/self_update.py` — какую ветку проверять при запуске, задаёт файл
`update_branch.txt` рядом с программой (не в git, свой у каждой копии): "Stable" у рабочей,
"alpha/Mzs7" у копии для разработки. Нет файла — по умолчанию "Stable".

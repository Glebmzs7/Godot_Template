# Godot_Template_<ИмяЭтогоПроекта>

Слой кастомизации шаблонных классов под нужды именно этого проекта. Классы здесь
наследуют/переопределяют классы из соседней `Godot_Template/` (которая — чистая копия ветки
`Stable` шаблона и никогда не редактируется напрямую).

Правила:
- `Godot_Template/` не трогаем — только читаем/наследуем из неё.
- Если правка тут логически относится не только к этому проекту, а к общей функциональности —
  она предлагается шаблону через `alpha/<ИмяЭтогоПроекта>` (команды — в
  `Godot_Template/UPDATING.md`, раздел «Отправить правки обратно»).
- После каждого `subtree pull` шаблона — сверяться: если то, что здесь переопределено, теперь
  один в один есть в обновлённом `Godot_Template/`, переопределение убирается и код проекта
  переключается на `Godot_Template` напрямую.

Пока пусто — переопределений ещё не заводили.

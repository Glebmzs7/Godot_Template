## Интерфейс / Class_UI

- **Развить `ShablonUI.md`** — 26.09 — пользователь: "его надо развить". По проверке в Godot 4.7
  10 свойств в заготовках не существуют у своих типов: Control `rect_min_size`
  (→ `custom_minimum_size`), `rect_clip_content` (→ `clip_contents`); Label `bbcode_enabled`
  (есть только у RichTextLabel), `line_spacing` (→ `theme_override_constants/line_spacing`);
  BaseButton `flat` (есть у Button), `group` (→ `button_group`); Button `vertical_alignment`
  (у Button такого нет, есть только `vertical_icon_alignment` для иконки); TextureButton `expand` (→ `ignore_texture_size`);
  H/VBoxContainer `separation` (→ `theme_override_constants/separation`). Также убрать из заготовок
  `__Path_to_the_node_location_S` (выставляется автоматически).
- **`fxC_ZoneReplacement` — отложено (27.09)** — пользователь: закомментировать с пометкой «отложено»; не рабочая (`erase()` без аргумента,
  последняя строка ничего не делает), нигде не вызывается.
- **Пересоздание ноды с детьми** — 26.09 — баг подтверждён запуском (см. чат 26.09): при смене
  `__Data_D`/`__Node_D` дети уничтожаются, запись в реестре остаётся с мёртвой нодой.
  `TestInterface` проходит ложно — нужен тест с `is_instance_valid` + исправление в
  `_fC_SyncExistingNode` (создавать через `fC_MassCreatingNode_0001`, чистить записи детей).
